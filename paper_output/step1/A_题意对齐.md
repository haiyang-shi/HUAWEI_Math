# A 题意对齐
## 问题一
- 任务类型：机理/仿真与参数校准
- 题意摘要：一维单电池瞬态自冷启动模型建立及验证
- 基线模型：备注1的常温一维传热传质与电压模型
- 改进路线：有限体积多相冷启动模型：水/冰相变、有效孔隙率与扩散、反应面积反馈
- 验证计划：-20摄氏度校准少量参数，-25摄氏度留作独立验证；温度、电压逐时残差和题定相对误差；水质量与能量守恒、非负性、网格收敛、相变参数敏感性
- 建议图表：电压和温度实验/模型对照及残差；最大冰体积分数时间曲线和厚度剖面；冰相变参数敏感性与网格收敛对照

## 问题二
- 任务类型：优化/规划
- 题意摘要：给定电荷量约束下的电堆自冷启动策略建模与优化
- 基线模型：线性规划、整数规划或可行规则基线
- 改进路线：多目标规划、启发式算法、遗传算法或模拟退火
- 验证计划：可行性检查；约束满足率；与基准策略对比；敏感性分析
- 建议图表：方案对比柱状图；约束满足情况图；敏感性分析折线图

## 问题三
- 任务类型：多相机理仿真约束下的恒功率优化
- 题意摘要：在 −30 ℃ 下分别优化纯预加热与恒定功率协同启动。纯预热应先无载加热至五片均超过 0 ℃，再开始加载电流；题定 0→0.3 A·cm⁻²、60 s 坡升仅用于协同启动等非纯预热工况。
- 输入：问题1单片多相模型、问题2五片热耦合模型、每片 0—1 W·cm⁻² 恒定加热功率、25 cm²加热面积、−30 ℃初始及环境温度。
- 输出：两类策略的五片功率、加热时间、分片与总辅助能耗、总启动时间、全过程最低电压、最大局部冰体积分数和启动结果。
- 关键约束：五片平均温度全部高于 0 ℃；局部冰体积分数低于0.99；加载全过程各片电压不低于0.30 V。纯预热后衔接问题2最优线性加载，不增加瞬时0.3 A·cm⁻²阶跃。
- 模型路线：五片独立有限体积多相模型 + 七节点端板热网络 + 纯预热解析热网络/SLSQP + 协同黑箱边界搜索与细网格复核。
- 验证计划：4.05/4.10 s可行边界；84/112格及细时间步复核；质量和能量守恒；纯预热加载后5 s跟踪。
- 建议图表：两类策略温度—电压—冰量轨迹；各片辅助能耗分配柱状图；协同临界可行性对照表。
