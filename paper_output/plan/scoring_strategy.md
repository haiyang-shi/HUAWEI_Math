# 评分闭环与模型路线策略

本文件由 `modeling-paper-rubric-and-model-selector` 根据结构化题意分析生成，用于指导后续建模、证据审计与正式写作。

## 全局原则

- 每一问必须形成“任务定义 -> 模型建立 -> 求解结果 -> 验证检验 -> 回答原问”的闭环。
- `model_route.json` 是后续写作的模型路线交接单，不能在正文生成时随意偷换主模型。
- `rubric_alignment.json` 是评分点与证据形式的映射，QA 应逐条检查是否落实。

## 问题一

- 任务类型：机理/仿真与参数校准
- 核心目标：一维单电池瞬态自冷启动模型建立及验证
- 基线模型：备注1的常温一维传热传质与电压模型
- 主模型：有限体积多相冷启动模型：水/冰相变、有效孔隙率与扩散、反应面积反馈
- 模型理由：该问属于“机理/仿真与参数校准”任务，有限体积多相冷启动模型：水/冰相变、有效孔隙率与扩散、反应面积反馈 能在保留可解释性的同时承接题目约束：五层一维膜电极区域，低温水蒸气/液态水/冰分相。
- 公式要求：定义状态变量与参数；写出状态转移或动力学方程；说明参数校准与情景设定
- 验证计划：-20摄氏度校准少量参数，-25摄氏度留作独立验证；温度、电压逐时残差和题定相对误差；水质量与能量守恒、非负性、网格收敛、相变参数敏感性
- 图表证据：电压和温度实验/模型对照及残差；最大冰体积分数时间曲线和厚度剖面；冰相变参数敏感性与网格收敛对照
- 评分点落位：题意覆盖 -> 问题一模型建立/问题一结果分析/问题一模型检验；模型合理性 -> 问题一模型建立/问题一结果分析/问题一模型检验；结果可信 -> 问题一模型建立/问题一结果分析/问题一模型检验；图表证据 -> 问题一模型建立/问题一结果分析/问题一模型检验
