# 本题技能配置

本项目采用 `.agents/project_config.json` 作为12个已安装技能的共同配置。原始 PDF、Word 和 Excel 保持在项目根目录及原附件目录；`problem_files/` 存放 PDF 与两份 Excel 的工作流输入副本，便于标准技能读取。PDF 是当前题面依据。自动生成的题意与路线契约位于 `paper_output/`；针对问题1的模型、代码、原始数据摘录、结果、图表和独立报告位于 `问题1/`。

## 阶段与边界

1. `paper-workflow-orchestrator` 完成输入预检；`problem-doc-model-selector` 抽取四问；`modeling-paper-rubric-and-model-selector` 生成路线。自动抽取的“问题1=预测/回归”须校正为“多相传热传质机理仿真与参数校准”。校正由 `.agents/configure_q1_route.py` 完成。
2. `data-cleaning-and-visualization` 的通用清洗规则不能自动改写电流、电流密度或零下温度。附件2的第一行为标题、第二行为列名、其后184行才是各工况测量值。专用读取与校验由 `问题1/data.py` 执行。
3. `sympy` 可用于核对方程，`pymoo` 在问题2至4需要多目标优化时再安装和启用；本次问题1通过 SciPy 求解与校准。脚本和技能包相互独立，避免把通用代理模型当成氢燃料电池机理模型。
4. `quality-assurance-auditor` 的正式证据门禁面向四问完整论文。问题1阶段先执行专用物理与数值检查，不声称四问论文已通过最终门禁。`paper-formal-writer` 和 `paper-micro-unit-generator` 留待全部结果可复现后使用。
5. `context-memory-keeper` 记录数据口径和阶段状态。题目中的 MathType/OLE 方程需要人工逐项复核，不能由普通 Word 文本抽取代替。

## 已发现的原题与数据口径疑点

- 附件1给定活化面积25 cm²，附件2电流除以电流密度对应约303至311 cm²。因此问题1数值输入采用附件2的电流密度列，并保留电流列供质量检查。
- 题面将冰体积分数定义为冰体积除以控制体总体积，0.99堵塞阈值与约0.39–0.42的催化层孔隙率不相容。模型分别保存控制体冰体积分数与孔隙冰饱和度。
- 实验到36.6 s仍低于0℃，不能直接验证融冰、启动成功或极低温外推。

## 可复现命令

从项目根目录运行 `D:/Anaconda/python.exe 问题1/run.py`。结果写在 `问题1/results/`，报告为 `问题1/问题1解决报告.md`。运行环境与输入文件的散列写在 `问题1/results/run_manifest.json`。
